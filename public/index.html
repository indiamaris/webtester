simple-test

Penetration testing tool for web applications

JWT Forgery Tester

Forge a JWT using a known secret. Use with hardcoded JWT_SECRET from your app config.

CORS Misconfiguration Test

Test if target API allows requests from arbitrary origins. Run from this page (different origin).

XSS Payload Generator

Copy payloads to inject in Strapi CMS or other v-html fields. Click to copy.

File Upload Vulnerability Test

Test upload endpoints for missing validation (MIME, extension, size).

API Probe

Probe API endpoints with different auth headers and methods.
